# Project BAYKUSH

Project BAYKUSH is an independent cyber, geopolitical, and strategic intelligence engineering initiative.

The public site presents four connected capabilities:

- **CİTEM** — cyber threat intelligence
- **İDRAK** — intelligence production
- **KARARGÂH** — strategic command and decision support
- **RASAT / The Eye** — research, monitoring, and published assessments

## Website

The first release is a responsive Next.js homepage with:

- a dark blue intelligence-interface visual system
- a restrained owl silhouette with animated cyan eyes
- a lightweight animated SVG globe
- four ecosystem module cards
- research and assessment previews
- reduced-motion accessibility support

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production build

```bash
npm run build
npm run start
```
